# Database Creation App

This application creates a SQLite database (`enrollments.db`) from raw enrollment data. It performs a complete ETL (Extract, Transform, Load) pipeline:

1. **Clean** raw enrollment data (Spanish CSV with original headers)
2. **Aggregate** section statistics from cleaned data
3. **Load** all data into a SQLite database

## Input Files

### Location

Place your input files in the `input/` directory:

| File Type | Location | Description |
|-----------|----------|-------------|
| Raw enrollment data | `input/raw/*.csv` | Original CSV with Spanish headers |
| Prerequisites | `input/prerequisites/*.json` | Course prerequisite mappings |

### Raw Data CSV Format

The raw CSV file must have the following Spanish column headers:

| Column | Description |
|--------|-------------|
| `CODIGO` | Student ID |
| `PERIODO` | Academic term (e.g., 202320) |
| `MATERIA` | Course code (e.g., MATE-1010 or MATE-1010-Homologada) |
| `SECCION` | Section number |
| `DESCRIPCION_CAMPUS` | Campus name |
| `CALIFICACION_PARCIAL` | Partial grade |
| `CALIFICACION_FINAL` | Final grade |
| `DESCRIPCION_ESTADO_MATERIA` | Course status description |

Example row:

```csv
F1;CODIGO;PERIODO;MATERIA;...;CALIFICACION_PARCIAL;CALIFICACION_FINAL;SECCION;...;DESCRIPCION_ESTADO_MATERIA
1;22070831;202320;IIND-3221;...;3.06;3.08;15;...;
```

### Prerequisites JSON Format

Each JSON file should contain a dictionary mapping course codes to their prerequisites:

```json
{
  "MATE-1201": null,
  "ISIS-1107": ["ISIS-1221", "MATE-1201"],
  "ISIS-1106": [["ISIS-1104", "ISIS-1107", "MATE-1102"], "ISIS-1225"]
}
```

- `null`: No prerequisites
- `["A", "B"]`: Both A AND B required
- `[["A", "B"], "C"]`: (A OR B) AND C required

## Database Schema

The database is created in **read-only mode** with optimized indexes for query performance.

### Table: `enrollments`

Stores individual student enrollment records.

```sql
CREATE TABLE enrollments (
    student_id INTEGER NOT NULL,
    academic_term INTEGER NOT NULL,
    course_code TEXT NOT NULL,
    section INTEGER NOT NULL,
    campus_description TEXT,
    partial_grade TEXT,
    final_grade TEXT,
    course_status_description TEXT,
    course_outcome TEXT NOT NULL CHECK (course_outcome IN ('P', 'F', 'W')),
    PRIMARY KEY (student_id, academic_term, course_code)
) WITHOUT ROWID;
```

**Indexes on `enrollments`:**

| Index | Columns | Use Case |
|-------|---------|----------|
| PRIMARY KEY | (student_id, academic_term, course_code) | Student enrollment history |
| `idx_enrollments_course_term_outcome` | (course_code, academic_term, course_outcome) | Pass/fail rates by course and term |
| `idx_enrollments_student` | (student_id) | All courses for a student |
| `idx_enrollments_course` | (course_code) | All enrollments for a course |
| `idx_enrollments_term` | (academic_term) | All enrollments in a term |

### Table: `section_stats`

Stores aggregated statistics per course section.

```sql
CREATE TABLE section_stats (
    course_code TEXT NOT NULL,
    academic_term TEXT NOT NULL,
    section INTEGER NOT NULL,
    enrolled INTEGER NOT NULL CHECK (enrolled >= 0),
    passed INTEGER NOT NULL CHECK (passed >= 0),
    failed INTEGER NOT NULL CHECK (failed >= 0),
    withdrawn INTEGER NOT NULL CHECK (withdrawn >= 0),
    PRIMARY KEY (course_code, academic_term, section),
    CHECK (enrolled = passed + failed + withdrawn)
);
```

**Indexes on `section_stats`:**

| Index | Columns | Use Case |
|-------|---------|----------|
| PRIMARY KEY | (course_code, academic_term, section) | Specific section lookup |
| `idx_section_stats_term` | (academic_term) | All stats for a term |
| `idx_section_stats_course` | (course_code) | Historical stats for a course |

### Table: `course_prerequisites`

Stores course prerequisite relationships as JSON.

```sql
CREATE TABLE course_prerequisites (
    course_code TEXT PRIMARY KEY NOT NULL,
    prerequisites_json TEXT NOT NULL
);
```

**Indexes on `course_prerequisites`:**

| Index | Columns | Use Case |
|-------|---------|----------|
| PRIMARY KEY | (course_code) | Prerequisites for a course |

## Usage

### Quick Start

1. Place your raw data CSV in `input/raw/`
2. Place your prerequisites JSON in `input/prerequisites/`
3. Run the pipeline:

```bash
cd db_creation_app
python3 create_db.py --force
```

### Command Options

```
usage: create_db.py [-h] [--raw-data RAW_DATA] [--prerequisites-dir DIR]
                    [--output OUTPUT] [--force] [--skip-cleaning]

options:
  --raw-data PATH       Path to raw enrollment CSV (default: first CSV in input/raw/)
  --prerequisites-dir   Path to prerequisites JSON directory
  --output PATH         Path for output database (default: output/enrollments.db)
  --force               Overwrite existing database without prompting
  --skip-cleaning       Skip cleaning step, use existing files in cleaned/
```

### Examples

**Basic usage (uses default paths):**

```bash
python3 create_db.py --force
```

**Specify custom raw data file:**

```bash
python3 create_db.py --raw-data /path/to/my_data.csv --force
```

**Skip cleaning (reuse existing cleaned files):**

```bash
python3 create_db.py --skip-cleaning --force
```

## Pipeline Steps

The script executes five main steps:

### Step 1: Clean Raw Data

- Reads raw CSV with Spanish headers
- Normalizes course codes to pattern `XXXX-DDDD`
- Computes course outcomes (P=Pass, F=Fail, W=Withdrawn)
- Deduplicates by (student_id, academic_term, course_code)
- Outputs: `cleaned/main_table_*.csv`

**Cleaning Rules:**
- Courses with status containing "RETIRADO" → Withdrawn (W)
- Final grade >= 3.0 → Pass (P), < 3.0 → Fail (F)
- Symbolic grades: A, TR → Pass; R → Fail
- Falls back to partial grade if final grade unavailable

### Step 2: Aggregate Statistics

- Reads cleaned enrollment data
- Groups by (course_code, academic_term, section)
- Counts: enrolled, passed, failed, withdrawn
- Outputs: `cleaned/section_stats_*.csv`

### Step 3: Load into Database

- Creates SQLite database with schema and indexes
- Loads enrollments from cleaned CSV
- Loads section statistics from cleaned CSV
- Loads prerequisites from JSON files
- Outputs: `output/enrollments.db`

### Step 4: Validate Database

- Runs SQLite integrity check
- Reports record counts for each table
- Lists all created indexes

### Step 5: Finalize Database (Read-Only)

- Runs `ANALYZE` to update query planner statistics
- Switches from WAL to DELETE journal mode (single-file)
- Runs `VACUUM` to optimize storage
- Sets file permissions to read-only (444)
- Verifies database can be opened in read-only mode

**Read-Only Mode:**

The database is finalized in read-only mode to:
- Prevent accidental data modification
- Optimize for read performance
- Enable safe distribution of the database file

To modify the database, first change file permissions:

```bash
chmod u+w output/enrollments.db
```

## Troubleshooting

### Common Errors

#### "No CSV files found in input/raw/"

**Cause**: No raw data file in the input directory.

**Solution**: Copy your raw data CSV to `input/raw/`:

```bash
cp /path/to/datos_investigacion.csv input/raw/
```

#### "Raw data file not found"

**Cause**: The specified `--raw-data` path doesn't exist.

**Solution**: Verify the file path and try again.

#### Rows being dropped during cleaning

**Cause**: Rows are dropped when:
- Course code doesn't match pattern `XXXX-DDDD`
- Section is empty
- Cannot determine pass/fail outcome

**Solution**: Check the log file for details on dropped rows. This is usually expected behavior.

### Verifying the Database

After creation, verify the database contents:

```bash
sqlite3 output/enrollments.db "SELECT COUNT(*) FROM enrollments;"
sqlite3 output/enrollments.db "SELECT COUNT(*) FROM section_stats;"
sqlite3 output/enrollments.db "SELECT COUNT(*) FROM course_prerequisites;"
```

### Query Examples

```sql
-- Get pass/fail rates for a specific course
SELECT
    academic_term,
    SUM(passed) as total_passed,
    SUM(failed) as total_failed,
    SUM(withdrawn) as total_withdrawn,
    ROUND(100.0 * SUM(passed) / SUM(enrolled), 2) as pass_rate
FROM section_stats
WHERE course_code = 'MATE-1201'
GROUP BY academic_term
ORDER BY academic_term;

-- Get prerequisites for a course
SELECT course_code, prerequisites_json
FROM course_prerequisites
WHERE course_code = 'ISIS-1107';

-- Find students who failed a specific course
SELECT student_id, academic_term, final_grade
FROM enrollments
WHERE course_code = 'MATE-1201' AND course_outcome = 'F';
```
